Question 1: Create a class called Song in your preferred OOP language with private properties title and artist. Add public getter and setter methods to access and modify these properties, then create an object and update its title.
Answer:
#include <iostream>
using namespace std;

class Song
{
private:
    string title;
    string artist;

public:
    void setTitle(string t)
    {
        title = t;
    }

    string getTitle()
    {
        return title;
    }

    void setArtist(string a)
    {
        artist = a;
    }

    string getArtist()
    {
        return artist;
    }
};

int main()
{
    Song s;

    s.setTitle("Believer");
    s.setArtist("Imagine Dragons");

    cout << "Song: " << s.getTitle() << endl;
    cout << "Artist: " << s.getArtist() << endl;

    s.setTitle("Thunder");

    cout << "Updated song: " << s.getTitle() << endl;

    return 0;
}

Question 2: Build a class called InstaStory with a protected property storyViews. Create a subclass called SponsoredStory that can access and display the storyViews value.
Answer:
#include <iostream>
using namespace std;

class InstaStory
{
protected:
    int storyViews;

public:
    InstaStory()
    {
        storyViews = 500;
    }
};

class SponsoredStory : public InstaStory
{
public:
    void showViews()
    {
        cout << "Story views: " << storyViews << endl;
    }
};

int main()
{
    SponsoredStory s;

    s.showViews();

    return 0;
}

Question 3: 
Imagine a Flipkart-like app: create an abstract class Product with an abstract method upload(). Then, create two subclasses, Electronics and Clothing, that each implement the upload() method to print a different upload message.
Answer:
#include <iostream>
using namespace std;

class Product
{
public:
    virtual void upload() = 0;
};

class Electronics : public Product
{
public:
    void upload() override
    {
        cout << "Electronics product uploaded successfully." << endl;
    }
};

class Clothing : public Product
{
public:
    void upload() override
    {
        cout << "Clothing product uploaded successfully." << endl;
    }
};

int main()
{
    Electronics e;
    Clothing c;

    e.upload();
    c.upload();

    return 0;
}

Question 5: Explain in your own words the difference between encapsulation and abstraction, using examples from any social media app you use daily (like Instagram or WhatsApp).
Answer:
Encapsulation vs Abstraction

Encapsulation means keeping data protected inside a class and allowing access through methods.
Example: In Instagram, a user's password or phone number is private. We cannot directly change it. We use options like Change Password or Edit Profile to modify the data.

Abstraction means hiding the complicated internal working and showing only what the user needs.
Example: When I upload a photo on Instagram, I just select the photo and press Post. I don't need to know how Instagram stores the photo, processes it, or sends it to the server.
